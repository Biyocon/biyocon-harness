# Agent Note: Detective 搜索分页

Status: implemented

[English](2026-11-11-detective-search-pages.md) | 中文

## Problem

已批准的 [Detective 成本设计](../../proposed/feature/2026-11-05-conductor-detective-evidence-budget.md)指出，首次返回的大型搜索结果会产生可避免的输入成本。全局限制影响所有角色；改写旧结果可能丢失低价缓存命中。若字符限制无法让模型继续读取遗漏内容，重要证据就可能被隐藏。

## Decision

Detective 通过可信的子 agent（智能体）工具贡献获得作用域内的 `glob` 与 `grep` 定义，包括分析生产者调度路径。不支持工具贡献的 provider 仍被拒绝。其他角色保留继承的工具。批评者摘录、Auditor 证据、只读守卫和所有者授权保持不变。不修改核心包，也不提升记录格式版本。

配置由[工具 README](../../../../packages/conductor/tool-conductor/README.md)维护。完整分页文本包含摘要、已显示/总条目数、范围、截断标记及下一页游标，整体受 Unicode 字符上限约束。条目不会被切断；单个条目无法容纳时明确失败。Grep 保留独立受限的行预览：裁剪行带有标记，完整上下文需通过 `read` 获取。搜索命中不会自动成为已接纳或已验证的材料。

新搜索在发布游标前保存完整、已格式化的发现结果。Glob 采样先从每个顶层分组各取一个路径，再排列其余路径；禁用后保留搜索顺序。游标标识随机私有文件、SHA-256 摘要和下一条目的偏移。Run 与生产子 agent 的身份确定所有权。续页只接受游标，校验所有者、类型和摘要，并读取保存的结果，而非重新搜索变化后的文件。重新安装工具贡献仍使用同一存储。文件缺失、被改动、超限或无效时明确失败，不回退到工作区。

存储在配置的私有目录中独占创建随机文件，并使用仅所有者可访问的创建权限。内部文件版本 1 与 Conductor 记录版本无关。完整序列化文件有独立字节上限。显示的分页及其摘要使用现有持久化工具事件，不改写既有历史。移动目录或丢失文件会使已有游标不可用。不会自动清理文件。

Conductor 专家仍是一次性子 agent。恢复 run 会调度新的子 agent，其命名空间会拒绝旧游标。为同一子 agent 进行可信的重新安装后，可在进程重启后读取保留的分页；这并不引入可持续对话的 Conductor 子 agent。

Native/Code Mode 的规范返回值是受限字符串。渲染拒绝超限的策略替换值；最终内容限制覆盖错误和策略反馈。通用卡片区分新搜索与续页。缩短的显示内容背后不会隐藏完整规范结果。

## Alternatives considered

**降低全局条目上限。** 不采用，因为它影响其他角色，无法限制完整字符数，也无法提供稳定续页。

**每页重新搜索。** 不采用，因为文件变化可能导致遗漏、重复，或改变旧游标的含义。私有快照占用磁盘，但保持续页身份一致。

**裁剪历史或提前停止。** 两者都不能证明完成同样分析会更便宜。历史裁剪仍是可选、需测量的实验。Capture 索引仍是独立的阶段 A 工作；预算、覆盖记账和 `incomplete` 仍属于协调后的 v6 提案。

## Consequences

测试覆盖真实 ripgrep、作用域注册与资源释放、workflow/spawn 生产者调度，以及日志与模型可见分页的精确一致性，并覆盖损坏、所有权、Unicode 和限制回归。独立的源码启动进程验证源文件被替换后仍可读取保留的分页，并拒绝不同所有者或缺失存储。已构建的 headless Loader 快照在工作区被外部修改后仍读取全部五个 glob/grep 分页，保留后部发现，并完成正常的批评者/Auditor/Arbiter 路线。既有场景的 golden 保持不变。

额外分页与不变的输出成本可能抵消输入节省。历史 12.58% 价格等效场景不是已实现的节省。公开材料上的真实模型比较必须评估净价格和相关发现，包括后续分页。私有文件需要考虑保留与备份。验证不需要所有者的会话数据。
