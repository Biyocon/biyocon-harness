# Agent Note: Conductor 公开价格与证据测量

Status: implemented

[English](2026-11-11-conductor-public-cost-experiment.md) | 中文

## 问题

[Detective 设计](../../proposed/feature/2026-11-05-conductor-detective-evidence-budget.md)估算，缩短搜索结果可使价格降低 12.58%。额外分页、推理、缓存变化和返工可能抵消该收益。仅比较成功尝试，还可能隐藏未完成分析的成本。所有者优先考虑具有充分证据的完整分析所产生的账单。

## 决策

通过[公开实验](../../../../scripts/conductor-cost/README.md)，使用真正的 Loader、随版本提供的 Conductor 预设和官方模型，比较固定且已构建的运行时版本。两组使用完全相同的生成来源和任务、隔离状态、只读策略，并禁用 provider 自动重试。每个案例执行三次重复，交替组别顺序。保留固定观察器的 SHA-256 和每次尝试，包括所有者升级和停止；绝不覆盖失败试验来获得更好的样本。

一个案例在未接纳文件时施加广泛发现压力。另一个案例包含三个已接纳 capture，每个来源都有必需发现。确定性来源哈希和独立答案 manifest（元数据清单）绑定预期标识符与位置。分析器检查最终生产者实际接触的来源、已保存来源区间、未变化的哈希和文件清单；模型给出接受结论并不足够。当前请求文本、返回的结构化输出和被拒绝的工具调用不构成来源证据。发现的工作区观察不会获得已接纳材料身份。

观察器原样传递 provider 流块，每次调用仅记录一次用量。分析器按会话、轮次和步骤，将其与日志中的 assistant 消息核对。未缓存输入和缓存读取互不重叠；推理已包含在输出中。缺失的缓存写入量是未报告，不是零。缺失或无法定价的用量会使总价保持未知。重复工具结果字符数描述重传，而不是 provider 对 token 的归属分配。

采用 2026-11-11 核对的[官方价格](https://api-docs.deepseek.com/quick_start/pricing/)：Flash 每百万未缓存输入/缓存读取/输出 token 的非高峰费率为 0.15/0.003/0.60 美元。报告标准非高峰价格等值，不称其为账单或账户扣款。请求的 `deepseek-flash` 别名在文档中对应 DeepSeek-V4.1-Flash-1017；未固定实际权重。无法重置远端缓存状态，且[缓存命中为尽力而为](https://api-docs.deepseek.com/guides/kv_cache/)。

主要价格指标将全部尝试的成本除以通过指定来源/答案检查的完成数。同时列出完成数、各次费用、模型/工具调用次数、每个结果的字符数、输出和返工。仅发布生成的无正文元数据；完整请求、推理、会话和日志保留在本地。实验既不读取所有者会话，也不操作端口 10822 上的应用。

## 考虑过的替代方案

**仅用 token 总数或成功尝试的均值。** 否决：廉价缓存输入和失败尝试会扭曲所有者的金额目标。

**仅用 replay 或私人运行比较。** replay 能固定行为，但无法测量当前模型用量、缓存影响或费用。公开合成材料可在不披露私人来源的情况下复现。现有无密钥运行时快照仍然必需，不能被本实验取代。

**测量期间启用产品预算或主动裁剪。** 否决：两者都会改变实验处理。外部实验停止会被披露为失败，不是 v6 记账或效率收益。

## 后果

聚焦记账测试拒绝重复收费、未知用量、日志不匹配、伪造来源支持和仅成功样本的价格比较。[首次结果](../../../../scripts/conductor-cost/README.md#observed-experiment-2026-11-11)和[独立的指引修订后续实验](../../../../scripts/conductor-cost/README.md#guidance-follow-up-2026-11-11)保留失败尝试并披露 capture 价格回退。不同实验的对照组和缓存状态不同，因此不合并其试验。小样本无法证明普遍节省。独立答案资格检查针对指定关键发现，不覆盖每项语义断言或 Auditor 判断；附带断言和完整性仍需审查。空 Git 标记用于隔离指令，不检验 Git 验证。本测量补充现有 Detective 设计，不取代其源头限制、证据或 v6 决策。基准结果不会自动引入运行时、SDK 或记录格式变化。
