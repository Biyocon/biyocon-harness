# Agent Note：Conductor 子会话角色与精确尝试状态

Status: implemented

[English](2026-10-28-conductor-child-role-status.md) | 中文

## 问题

[Issue #28](https://github.com/Biyocon/biyocon-harness/issues/28)描述以 UUID 和通用提示标题标识专家的列表。角色本身不能确定哪一次返工收到了门禁决策；后续 Strategist 不能继承前一次的拒绝结果。

## 决策

Conductor 在父 Session 中记录模型不可见的 `conductor/child` 完整快照，包含具体子会话、运行、运行时角色、按角色递增的尝试编号、派发时历史偏移和生命周期状态。按 workflow id 精确匹配开始及结束事件，角色不取自标签、生成标题或提示文本。Ralph 通过共享运行器可信的 `observeRun` 钩子接收身份，不按时间或名称匹配其他工作流。

已保存的门禁检查点将决策关联至派发偏移所指向的已评估门禁。准入验证和跳过记录不成为子会话结果。返工计数使用相应门禁的独立预算。新子会话没有决策；每次尝试都单独保留。Ralph worker 只接收生命周期状态，Gate D 属于 Headsman 随后的报告。子会话失败或处置工作流时仍未结束，记录失败而不伪造门禁结果。执行完成不等于门禁通过。

共享 base 组合独立于活动 agent preset 挂载纯 `conductorChildren` 投影，使历史列表在 agent 释放和应用重启后仍可读取。独立 Conductor 组合可由工具注册同一投影。`session/end-seed` 清除继承的子会话。新增 Session 事件为必读事件，旧构建拒绝包含未知必读事件的日志。Conductor 检查点格式 3 和 SDK 协议不变。

现有子代理列表按精确父子地址选择显示数据。英/丹文本显示角色、尝试编号、生命周期及可选门禁结果；UUID 保留在次要文本和无障碍名称中。普通子代理保留原有标签、标题及导航。显示数据不增加模型输入、权限或运行时路由能力。头像和团队视图另行处理。

## 考虑过的替代方案

解析提示或标题无法确定运行时身份。按角色保留最新决策会丢失前次尝试，并把返工结果泄漏到后续子会话。仅保存在活动工作流中的数据无法在重启后重现目录。精确子会话快照消除这些歧义，无需修改通用子会话头或工作流线协议。

## 影响

持久化显示数据增加少量父事件，避免从可变标题推断角色或依赖活动工作流。完整快照便于重放和替换单个子会话。父投影避免修改通用子会话头和工作流协议，但展示历史目录的宿主组合必须挂载该投影。

## 验证

聚焦运行时测试覆盖独立 Strategist 尝试、工作流身份过滤、无伪造门禁的失败、投影重放及种子清除。英/丹客户端测试覆盖返工与运行状态，并保留普通子代理行为。已安装 preset 的 keyless runnable example 检查实际工作流子会话的角色数据，包括两次独立 Strategist 尝试。分支服务器上的真实简短回答分析提供 GUI 演示；媒体保存在独立 assets 分支。
