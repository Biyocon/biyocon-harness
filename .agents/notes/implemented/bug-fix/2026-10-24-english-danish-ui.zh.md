# Agent Note: 英文与丹麦文应用文案

Status: implemented

[English](2026-10-24-english-danish-ui.md) | 中文

## Problem

此 fork 面向英文与丹麦文用户。中文界面文案和未本地化的 Conductor 元数据使英文设置页混合显示多种语言。

## Decision

浏览器仅提供 `en` 和 `da`。浏览器偏好中没有受支持语言，或丹麦文字典缺少键时，使用英文后备文案。显式偏好仍按 [Host 支撑的 Web 偏好](2026-08-06-host-backed-web-preferences.md)持久化；其 schema 也接受已存储的旧值 `zh`；语言所有者将其解析为英文，不改写设置文档。其他未知值仍被拒绝。中文既不可选择，也不注册为界面语言。

功能插件拥有对等的英文与丹麦文字典。不依赖 Cordis 的展示组件以英文为默认值，并接受本地化标签属性。Chat 和已选调用详情向 diff、read、search 和 web 卡片传入同一组翻译标签。Trajectory 将当前翻译函数传入记录表与时间线，覆盖检查器标签页、状态、计时、空状态和无障碍名称；缓存的摘要随语言切换刷新。locale 插件使文档的 `lang` 属性始终等于当前语言，并在 dispose 时恢复原值。包括 Conductor 在内的五个内置预设均按当前语言解析名称与描述。内置预设的文件元数据使用英文，包括新副本继承的描述。自定义预设元数据、用户与模型内容、运行时提示词和双语开发文档不作翻译或过滤。

## Alternatives considered

已知权限预设 ID 使用各界面的英文或丹麦文字典，覆盖编辑器、命令弹窗和 Settings 行。Settings 控制器保留未翻译的 host 名称；视图在渲染时解析标签，因此切换语言也会更新已加载描述符的显示。仅未知的 host 配置名称保留 kebab-case 显示变换。由于禁止跨插件导入值，每个可独立加载的 UI 插件拥有私有格式化函数；权限插件的命令弹窗与 Settings 行共享一个函数，不新增公共导出。

保留中文作为隐藏后备语言仍会暴露不受支持的应用文案。仅在选择器中加入丹麦文会留下未翻译的功能字典与 Conductor 元数据。

## Consequences

结构化结果卡片共享一个内部溢出切换控件，由调用方提供标签和样式。保留多个独立副本会重复相同的无障碍与展开行为；共享组件保持渲染标记和英文默认值不变，不暴露额外的公共 UI 入口。

语言 schema 与注册表测试覆盖受支持的语言对及英文后备行为。浏览器场景执行真实组装后的设置页、语言持久化与内置预设选择；其无障碍快照记录本地化应用，而非 mock 组件。
