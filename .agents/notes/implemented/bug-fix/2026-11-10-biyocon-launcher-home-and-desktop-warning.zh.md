# Agent Note: Biyocon 启动器目录与桌面应用警告

Status: implemented

中文 | [English](2026-11-10-biyocon-launcher-home-and-desktop-warning.md)

## Problem

官方桌面应用与 Biyocon 可能在同一目录写入不兼容的凭据或投影缓存。继承的 `DSH_HOME` 也可能使 Biyocon 快捷方式使用非预期的数据目录。启动器互斥锁只协调 Biyocon 启动器，不协调官方应用。

## Decision

[启动器](../../../../start-biyocon.ps1)在启动服务器前将 `DSH_HOME` 设为 `$HOME\.dsh`，覆盖继承值。子命令继承该环境。若存在名为 `DeepSeek Harness` 的进程，启动器警告共享凭据和会话数据的风险，并提示所有者关闭官方应用。警告后继续正常启动流程，不终止任何进程。现有监听端口与 Biyocon 服务器检查仍决定复用、拒绝或启动服务器。

## Alternatives considered

**自动终止官方进程。** 所有者控制该应用及其未完成工作，因此不采用。

**仅依赖数据目录锁。** 锁只能协调遵守它的进程，不能假定官方桌面应用也遵守。进程警告仅作提示，也无法阻止其他进程在检查之后启动。

## Consequences

快捷方式始终选择所有者的标准目录。已运行的服务器保留自己的环境；打开浏览器不会更改其数据目录。启动器冒烟测试执行真实入口，使用合成进程与监听查询并拦截进程启动，在不访问会话文件、不启动任何应用的前提下覆盖桌面进程存在与不存在两种状态。
